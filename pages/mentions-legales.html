Protection des données personnelles (RGPD)

Ce générateur d'itinéraire touristique fonctionne principalement côté client (dans le navigateur) : les critères saisis (ville, catégories, rayon) sont utilisés pour interroger, selon le mode actif :

  • des données de démonstration locales (mode démo, sans envoi à un service tiers autre que le géocodage gratuit OpenStreetMap/Nominatim) ;
  • ou l'API Google Places / Google Maps (mode données réelles), si une clé API valide est configurée — dans ce cas, les requêtes sont envoyées directement à Google, conformément à leur propre politique de confidentialité.

Aucune donnée personnelle identifiante n'est collectée ni stockée par ce site pour son propre compte. La clé API Google, si renseignée, est conservée localement dans le navigateur de l'utilisateur (stockage local) et n'est jamais transmise à un serveur tiers autre que Google.
