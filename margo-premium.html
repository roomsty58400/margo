Données réelles via Google Places (optionnel)

Sans clé : recherche gratuite et illimitée via OpenStreetMap (données réelles, dans toutes les villes, mais parfois moins de photos/horaires/prix). Avec une clé Google valide : recherche Google Places en priorité (données plus riches), avec repli automatique sur OpenStreetMap si jamais Google est indisponible (quota, clé invalide...).

Dans Google Cloud Console, activez Maps JavaScript API, Places API (New) et Geocoding API, créez une clé, puis restreignez-la (référent HTTP = ce site). Ces API sont payantes au-delà du crédit gratuit mensuel de Google — chaque recherche interroge une catégorie par lieu sélectionné, et les suggestions de ville pendant la saisie utilisent aussi Places Autocomplete (sans clé : suggestions gratuites via OpenStreetMap à la place).

Itinéraire suggéré

Lien Google Maps → Waze

Colle n'importe quel lien Google Maps (généré par Margo ou copié ailleurs) pour obtenir le lien Waze équivalent. Waze ne gère qu'une seule destination à la fois (pas d'itinéraire à étapes multiples) : c'est donc la destination du lien collé qui est utilisée — le point de départ si le lien n'en a pas.
